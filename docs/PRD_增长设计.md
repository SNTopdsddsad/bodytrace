# PRD：BodyTrack 用户增长设计（激活 · 留存 · 分享）

版本：v0.1（草案）· 日期：2026-08-19 · 状态：待评审
关联：docs/BodyTrack_开发文档.md · 仓库：bodycheck
约束：本次为需求描述，不涉及代码实现；实现前需评审确认。

## 1. 背景与目标

- 背景：BodyTrack 1.0 功能齐备，但首开为空（无引导、无历史导入），无留存机制（无提醒/无连续激励/无回顾），无裂变载体。产品重心落在「记录」本身，而记录是成本不是收益。
- 目标（本期三件事）：
  1. 激活：把「有价值状态」提前到**首次打开** —— 一键导入全部历史体重，让趋势 / 达标结论在 Day 0 点亮。
  2. 留存：建立「日微反馈 + 周复盘 + 里程碑」三层反馈闭环，让用户明天还想打开。
  3. 分享：把周报 / 里程碑做成可分享的成果卡（本地生成、无账号、隐私可控），让留存资产复用于获客。

## 2. 设计原则（不违背产品既定口径）

- 无账号、无广告、无追踪、无内购：提醒与分享完全本地，不需要后端。
- 健康数据最小化：只申请用到的类型；首开先只申请体重（读），能量类型在自然场景二次引导。
- 权限请求永不发生在启动第一帧；都发生在用户主动动作之后。
- 达标 / 不达标结论只对完整 7 天窗口生效，首体验绝不读出「输」。
- 仅 iPhone，中文优先，iOS 18+。

## 3. 范围

本期（P0/P1）：
- 首开激活向导、Apple 健康全部历史体重导入
- 每日称重提醒（本地通知，默认开、可自选）
- 激励展示：滚动 7 天完成度 + 连续天数小火焰（首周即显示、断不惩罚）
- 周报：周一早复盘上周（自然周），首周豁免，非完整周不下结论
- 分享卡：每周回顾 / 里程碑 / 打卡三种主题，隐私边界见 FR-6
- 对应设置项与通知授权引导
- 数据导出 CSV（P1，作为隐私承诺兑现）

明确不做（本期）：账号/后端、首开即申请能量类型、Android / watchOS / iPad、国际化、付费。

P0 优先级排序：激活向导 + 全量导入 → 每日提醒 → 激励展示 → 周报 → 分享卡 → 设置项。

## 4. 功能需求

### FR-1 首开激活向导
- 触发：首次安装打开。
- 步骤：
  1. 价值主张一屏（示例文案：「你的体重历史已经在苹果健康里，BodyTrack 帮你把过去和今天放在一起看。」）
  2. 授权健康：点击按钮后请求读取体重（最小授权）。拒绝则跳过并保持本地可用。
  3. 导入历史：一次性导入全部历史体重（查询不设 90 天上限），按 healthKitUUID 去重 upsert；完成后展示「趋势图 + 距目标」第一结论（复用 WeightPace.arrival，窗口锁定近 90 天）。
  4. 设目标（可选）：填目标体重 → 立即显示「大约 X 周」，可跳过。
  5. 通知授权：在出结论之后请求本地通知，默认勾选开启每日称重提醒，可关闭。
- 分支：健康中无历史数据 → 引导手动记第 1 条体重 + 设目标，不进「导入」死路。
- 反例约束：向导不给「授权」设硬闸，不授权时全部本地功能照常。

### FR-2 历史全量导入
- 调整 reconcile 的查询窗口为全部历史（当前近 90 天）。
- 对账：按 healthKitUUID 去重 upsert，不因重复导入产生多条，不改写已有记录。
- 数据量：体重为纯文本，数据量极小；历史回灌行不产生 streak（见 FR-4）。
- 达标粗算必须锁定近端窗口（近 90 天），禁止用「全部」窗口计算达标时间。

### FR-3 每日称重提醒（本地通知）
- 默认开启、可自选；默认时间 07:30，设置可改。
- 通知内容不含体重数字，示例：「早上好，今天还没称重」。
- 抑制逻辑：当天已记录体重（manual 或当天新同步的 healthkit）→ 删除当天待发通知。
- 点按通知 → 打开 App 并直接进入 WeightEditorView（复用 bodytrack://log-weight）。
- 系统权限被拒 → 概览顶部显示「今日未称重」软提示条；设置提供「去系统设置开启」入口。
- 与周报错开：周一 07:30 称重 / 08:00 周报。

### FR-4 激励口径（连续火焰 + 近 7 天完成度）
- 日常展示一律滚动口径：「近 7 天称重 N 天」+「连续 N 天」小火焰。
- 火焰首周即显示（安装当天起计），断签不惩罚（不置灰清零，轻文案鼓励）。
- 新鲜记录判定：当天 manual 或当天经 Observer 进入的 healthkit 样本计入；历史回灌不产生 streak。
- 展示位：概览「最近」区 + 小组件（进度环，兼容现有 App Group 摘要与 Widget 只读约束）。
- 设置项：可关闭激励展示。

### FR-5 周报（本地通知 + 应用内视图）
- 触发：周一 08:00 本地通知；内容为「上周回顾」摘要（预先计算并写入通知文本）。
- 内容：上周体重起始 / 结束 / 变化 ±X kg + 7 天趋势；上周净热量合计 + 肥肉图；上周称重完成度（N/7）；距目标（近 90 天窗口粗算）。全部来自现有数据，无需新采集。
- 首周豁免：安装所在周（非完整周）不发布正式周报；上周 0 次称重不发布。
- 点按 → 打开 App 内「周报」页（新增视图）。
- 非完整窗口不下达标 / 未达标结论。

### FR-6 分享卡（每周回顾 / 里程碑 / 打卡）
- 本地生成图片，经系统分享面板分享，不自动写相册。
- 内容分三层（边界规则：变化量与达成默认上卡；绝对值与明细默认不上卡，除非用户逐条开启「显示体重数字」）：

| 主题 | 默认上卡内容 | 永不自动上卡 |
|---|---|---|
| 每周回顾 | 称 N 天、连续 M 天、变化 ±X kg、肥肉图克数 | 当前体重绝对值、饮食明细 |
| 里程碑 | 目标达成 + 连续 X 天 | 体重数字（默认只写目标达成，可开关） |
| 打卡 | 纯火焰 + 连续 N 天 | 任何数值 |

- 分享前必须在 App 内预览再弹系统面板；一张卡一个主题，避免组合信息反推隐私。
- 无推广水印；小字「数据来自 BodyTrack，内容由你选择分享」。
- 分享卡不入 SwiftData / 不入 CloudKit。

### FR-7 设置项
- 每日称重提醒：开/关 + 时间（默认 07:30）
- 周报：开/关（默认开）
- 激励展示：开/关（默认开）
- 通知权限被拒时的引导入口（跳系统设置）
- 数据导出 CSV（P1）
- 说明：目标 / 授权 / 单位等沿用现有设置。

## 5. 非功能需求

隐私与合规：
- 本地通知默认不含体重数字；分享卡不收集、不追踪。
- 隐私政策补充：「可主动生成并分享回顾卡片，内容由用户选择，BodyTrack 不收集」。
- HealthKit 只申请用到的类型；首开不弹第一帧；不申请 dietaryEnergyConsumed；不写医疗 / 减肥疗效文案。

审核：
- 激活向导的「授权」不是硬闸；不授权全部功能可用。
- 分享卡属于用户主动生成的图片、由用户自行分享，App 不收集，不影响现有营养标签。

性能：
- 全量历史导入异步批处理、不阻塞 UI。
- 周报预先计算、通知内容预生成；分享卡 PNG 本地生成不入库。

## 6. 成功指标

- 北极星：每周活跃称重用户数（每周至少记录 / 同步一次体重）。
- 激活：安装后 7 天内完成 ≥3 次称重；安装后 7 天内首次完成历史导入。
- 留存：安装后第 7 / 第 30 天留存（App Store Connect Analytics，设备级，无需 SDK）。
- 周报：周报通知点按率 → App 内周报打开（需轻量本地记录，见风险）。
- 分享：分享卡生成/分享次数（本地打点，需单独决策是否引入，本期默认不引入）。

## 7. 风险与边界

- 达标窗口污染：目标结论严格锁定近 90 天窗口。
- 审核风险：权限请求时机与「授权不是硬闸」必须守住。
- 通知打扰：默认仅两条（每日称重 + 周一周报），其余全部可关、默认关。
- 无分析 SDK：用 App Store Connect 分析 + 亲测；是否引入轻量本地统计需单独决策，本期默认不加。
- 历史导入可能拉长首开流程：异步导入 + 明确分步反馈，避免等待感。

## 8. 代码 / 文档映射（实现时参考）

复用：HealthKitWeightService.reconcile（改窗口）、WeightPace.arrival / trend（锁近端窗口）、TodayGlance、WidgetSnapshot + App Group 摘要、体重深链、WeightEditorView 快速记录。

新增：首开向导视图、全量导入调用、本地通知管理（请求 / 调度 / 取消）、streak 计算与新鲜度判定、周报视图、分享卡渲染、设置项三个开关 + 导出 CSV。

验收建议（对齐现有 A1–A10 风格）：
- G1 首次安装进入向导，授权后一次性导入全部历史并点亮趋势 / 达标结论。
- G2 授权拒绝时全部本地功能可用，后续可从「从健康同步」再授权。
- G3 每日提醒默认开：07:30 触发，当天已称重则不再提醒；通知不含体重数字。
- G4 激励展示：首周即显示火焰；历史回灌不产生 streak；断签无惩罚文案。
- G5 周报周一 08:00 发送复盘上周；安装当周与 0 记录周不发布。
- G6 分享卡：三主题内容符合 FR-6 边界；分享前预览；无相册自动写入。
- G7 新设置项可逐个开关；通知被拒时 App 内有降级提示与引导。
